个人时间记录工具 Windows 绿色版 v0.5.0
========================================

使用方法
--------
1. 请先完整解压 ZIP，不要直接在压缩包内运行。
2. 双击“PersonalTimeTracker.exe”。
3. 首次启动会自动创建并初始化 data、config 和 backups 文件夹。

数据说明
--------
- data：每周时间记录。
- config：分类、颜色和彩带开关等配置。
- backups：预留备份目录。
- 更新软件时，请保留以上三个文件夹，只替换 EXE 和 app 文件夹。

注意事项
--------
- 软件不需要安装 Python、Node.js 或 npm，也不需要联网。
- 请把整个软件放在有写入权限的位置，例如“文档”或普通磁盘文件夹；不要放进 Program Files。
- Windows 10/11 通常已包含 Microsoft Edge WebView2 Runtime。若窗口无法启动，请安装或修复该运行时。
- 如果同一软件已打开，再次双击不会启动第二个实例。
- 如需完整备份，请同时复制 data 和 config 文件夹。
